# Data-analysis-of-Pakistan-s-largest-e-commerce-dataset-using-python
This folder contains coding file for the data analysis of Pakistan's largest E-commerce dataset using python data analysis libraries: panda and numpy.
The purpose is to explore all of the commands that the panda libraries have built-in for the purpose of data analysis. This code also uses matplotlib, seaborn library to represent the metrics and findings, along with sklearn, which is used for metrics evaluation.
